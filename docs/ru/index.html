Разница ракурсов превращается в глубину.

Близкий объект смещается между изображениями двух сенсоров сильнее, чем далёкий. По этому смещению — диспаратности — драйвер оценивает глубину.

Ближе · 0,6 м Дальше · 2,0 м

Найти одну точку дважды.

Подвигайте ползунок расстояния. В правом ракурсе человек смещается по горизонтали: чем он ближе, тем сильнее смещение. Стереоалгоритм ищет такие соответствия по изображению.

Глубина — это оценка.

Совпадения образуют карту диспаратности меньшего разрешения. Однотонные стены, отражения и перекрытые края дают ненадёжные совпадения. Драйвер отбрасывает и фильтрует их перед использованием.

Размытие следует за расстоянием.

Человек остаётся в фокусе. Сила размытия фона зависит от его удаления от плоскости фокуса. Фильтрация с учётом границ и композиция помогают не размывать сам объект.

Это упрощённая интерактивная схема, а не запись с камеры и не симуляция полного стереоалгоритма.

1

Выровнять ракурсы

Стереокалибровка исправляет вертикальное смещение и поворот перед поиском совпадений.

2

Сопоставить и проверить

Census и SGM по четырём направлениям находят диспаратность. Проверка уверенности и согласованности ракурсов отбрасывает ошибки.

3

Стабилизировать глубину

Заполнение пропусков, временное сглаживание и guided-фильтр уточняют глубину, сохраняя границы изображения.

4

Собрать изображение

Анализ объекта задаёт фокус и экспозицию. GPU соединяет резкого человека с размытым по глубине фоном.

Почему второй ракурс меньше

Основное изображение остаётся 1920×1080. Второй сенсор передаёт 960×540 внутри упакованного потока 2448×1088. Сопоставление работает примерно в 640×360, затем guided-фильтр привязывает оценку глубины к итоговому изображению. Два полных потока 1080p60 превысили бы доступную пропускную способность USB камеры. Эта схема сохраняет полное разрешение основного кадра, используя второй ракурс для геометрии.

Ближе примерно 0,5 м глубина становится менее надёжной. Прозрачные поверхности, повторяющиеся узоры и перекрытия всё ещё могут давать артефакты: это не прецизионный датчик глубины.

Что вы получаете

У камеры PlayStation 5 HD Camera два сенсора Full HD. Драйвер использует основное изображение для видео, а второй ракурс — для оценки глубины сцены.

Родные 1080p при 60 к/с

Каждая программа получает Full HD при 60 кадрах в секунду прямо с сенсора камеры, без растягивания. Прошивка Sony ограничивает 1080p тридцатью кадрами, изменения драйвера разрешают 60.

Размытие фона по настоящей глубине

Глубину дают два сенсора (стерео-сопоставление на видеокарте), поэтому размытие идёт по вашему настоящему контуру и расстоянию. Включается как собственные эффекты камеры Windows: Параметры → Bluetooth и устройства → Камеры → PS5 Camera.

Фокус по вашему силуэту

Уши, волосы и наушники драйвер находит по вашему силуэту, чтобы сохранить их в фокусе и размыть комнату за вами. Сложные края могут давать артефакты.

Экспозиция по вам

С включённым боке яркость меряется по вашей голове, а не по всему кадру: на фоне яркого окна вы больше не превращаетесь в тёмный силуэт.

Чистая картинка в полутьме

Шумоподавление следит за движением, чтобы уменьшить шлейфы, а защита от мерцания помогает бороться с полосами и пульсацией от ламп.

Работает во всех программах

На Windows камера видна как «PS5 Camera» в Zoom, Teams, Discord, Telegram, OBS, браузерах и приложении «Камера», без драйвера ядра и тестового режима.

Как это устроено на Windows

Всё работает в пользовательском режиме, на собственном стеке камер Windows.

Подключение

Камера стартует в загрузочном режиме; служба драйвера загружает в неё прошивку через встроенный в Windows WinUSB.

Камера появляется

Она переподключается как обычная UVC-камера со стандартным драйвером Windows.

Глубина на видеокарте

Device MFT внутри Windows Camera Frame Server считает глубину (census + SGM) и размытие на Direct3D 11.

Её видят программы

Программы получают «PS5 Camera» через Media Foundation, WinRT и DirectShow.

Установка

Нужен порт USB 3: в USB 2.0 камера отдаёт только 640×400. Переходник не нужен.

Windows 11

  • Скачайте PS5CameraDriver-ru.msi (на английском — PS5CameraDriver.msi) и запустите.
  • В программах выберите «PS5 Camera». После первой установки боке включено.
  • Нужны права администратора. Пока релизы без цифровой подписи, SmartScreen может предупредить о неизвестном издателе.
  • Установка без окон, из консоли администратора:
msiexec /i PS5CameraDriver-ru.msi /qn BOKEH=on

Linux

  • Из PS5CameraDriver-linux.zip; нужны systemd и udev. Выберите «USB Camera-OV580» (обычная камера) или, с боке, «PS5 Camera».
  • --bokeh on добавляет экспериментальное боке: x86_64 с glibc 2.34+ (Ubuntu 22.04, Debian 12, Fedora 35 и новее), видеокарта с Vulkan 1.1. Установщик ставит модуль ядра v4l2loopback; при Secure Boot на следующей перезагрузке выберите «Enroll MOK».
sudo bash install.sh --bokeh on

macOS

  • Из PS5CameraDriver-macos.zip; камера 1080p, без боке. В программе выберите «USB Camera-OV580».
  • Нужны Command Line Tools: xcode-select --install.
sudo bash install.sh

Пакет winget (KROU4.PS5CameraDriver) на проверке. Установщик скачивает оригинальную прошивку камеры Sony из сторонних копий на GitHub, проверяет её и вносит изменения драйвера. На Windows без интернета установка всё равно завершается, а прошивку позже соберёт служба; на Linux и macOS установщику нужен интернет, либо положите оригинал рядом с ним как sony-firmware.bin. Подробности: Windows, Linux, macOS.

Описание версии и загрузки

Вопросы

Ответы на то, что спрашивают о камере PS5 на компьютере.

Можно ли подключить камеру PS5 к компьютеру?

Да. Этот бесплатный драйвер с открытым кодом делает камеру PlayStation 5 HD Camera (CFI-ZEY1) обычной веб-камерой: на Windows 11 — родные 1920×1080 при 60 к/с и по желанию размытие фона по настоящей глубине, на Linux — 1080p (боке экспериментально), на macOS — 1080p без боке.

Нужен ли переходник для камеры PS5 на ПК?

Переходник не нужен: камера подключается в порт USB 3. В порту USB 2.0 камера отдаёт только 640×400.

Работает ли камера PS5 в Zoom, Teams, Discord и OBS?

Да, во всех программах, которые работают с веб-камерами: Zoom, Microsoft Teams, Discord, Telegram, OBS Studio, браузерах и приложении «Камера» Windows. На Windows и на Linux с боке камера называется «PS5 Camera», на macOS и на Linux без боке — «USB Camera-OV580».

Как размывается фон без нейросетей?

У камеры два сенсора. Драйвер сравнивает два изображения стерео-алгоритмом (census-преобразование и semi-global matching) на видеокарте, получает карту диспаратности меньшего разрешения, привязанную к итоговому изображению, и размывает то, что дальше человека, как объектив с малой глубиной резкости. Нейросети не используются.

Какой нужен компьютер?

На Windows: Windows 11, порт USB 3 и видеокарта с Direct3D 11, встроенная графика тоже подходит. Обработка работает на GPU; скорость зависит от видеокарты, сцены и настроек. Измерения текущей версии приведены в разделе производительности. На Linux для боке нужен Vulkan 1.1; обычной камере на Linux и macOS видеокарта не нужна.

Это безопасно? Ставится ли драйвер ядра?

На Windows кода в ядре нет, тестовый режим не нужен. Эффект работает в пользовательском режиме как Device MFT внутри Windows Camera Frame Server, а для загрузочного режима камеры используется встроенный в Windows драйвер WinUSB: чтобы поставить этот пакет драйвера, установщик добавляет в доверенные хранилища сертификат, созданный на вашем компьютере, и сразу удаляет его закрытый ключ, так что ничем другим им подписать нельзя. На Windows в сеть ничего не отправляется, кроме скачивания прошивки. На Linux боке использует модуль ядра v4l2loopback, который ставит установщик. Исходный код открыт под GPL-3.0.

Зачем установщик скачивает прошивку Sony?

Камере нужна прошивка при каждом подключении. Прошивка Sony не распространяется с драйвером: установщик скачивает оригинальный образ из сторонних копий на GitHub, проверяет его SHA-256 и вносит изменения драйвера — 90 байт (1080p при 60 к/с, режим глубины, автоматическая экспозиция). На Windows без интернета установка всё равно завершается, а прошивку позже соберёт служба; на Linux и macOS установщику нужен интернет или оригинал рядом с ним как sony-firmware.bin.

Подойдёт ли камера PS4?

Нет. Драйвер только для камеры PlayStation 5 HD Camera (CFI-ZEY1). Камера PS4 — другое устройство, и она не поддерживается, даже через USB-переходник.

Какие есть ограничения?

Камерой пользуется одна программа за раз, как с любой веб-камерой. Глубину камера измеряет примерно с полуметра: то, что ближе, размывается неровно. Боке на Linux экспериментальное, а на macOS его нет (нужно системное расширение камеры, которое macOS запускает только с подписью разработчика Apple).

Это бесплатно?

Да. Драйвер бесплатный, с открытым кодом под GNU GPL 3.0. Прошивка камеры принадлежит Sony и в проект не входит.
